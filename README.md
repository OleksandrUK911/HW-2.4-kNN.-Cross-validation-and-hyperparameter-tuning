# 📌 Прогнозування відтоку клієнтів банку: kNN і тюнінг гіперпараметрів

## 🎯 Про проєкт

Це домашнє завдання присвячене побудові та оптимізації моделей класифікації для прогнозування відтоку клієнтів банку (Bank Customer Churn Prediction). В рамках проєкту реалізовано порівняльний аналіз методів машинного навчання, використано різні техніки оптимізації гіперпараметрів та проведено детальну оцінку якості моделей.

## 🎓 Що реалізовано

### 1️⃣ **Базова модель kNN**
Побудовано класифікатор k-найближчих сусідів з параметрами за замовченням. Проведено оцінку якості моделі через метрику AUROC на тренувальному та валідаційному наборах. Виконано аналіз bias/variance trade-off для визначення проблем перенавчання або недонавчання.

### 2️⃣ **Оптимізація kNN через GridSearchCV**
Реалізовано пошук оптимального значення гіперпараметра `n_neighbors` (від 1 до 20) з використанням GridSearchCV. Застосовано 5-fold кросвалідацію з метрикою ROC AUC. Найкраща модель збережена як `knn_best` та порівняна з базовою версією.

### 3️⃣ **GridSearchCV для дерева рішень**
Виконано вичерпний пошук оптимальних гіперпараметрів для DecisionTreeClassifier:
- `max_depth`: від 1 до 20 з кроком 2
- `max_leaf_nodes`: від 2 до 10 з кроком 1

Використано 3-fold кросвалідацію, виміряно час виконання пошуку. Найкраща модель `dt_best` оцінена за AUROC та порівняна з ручним підбором параметрів.

### 4️⃣ **RandomizedSearchCV для дерева рішень**
Застосовано RandomizedSearchCV з розширеним простором гіперпараметрів (40 ітерацій):
- `criterion`, `splitter`, `max_depth`, `max_leaf_nodes`
- `min_samples_split`, `min_samples_leaf`, `max_features`

Проведено порівняння з результатами GridSearch, проаналізовано відмінності в параметрах та їх вплив на якість моделі.

### 5️⃣ **Підготовка submission для Kaggle**
Створено pipeline для обробки тестових даних та генерації файлу `submission.csv` з ймовірностями відтоку клієнтів. Реалізовано коректне застосування навченого препроцесора до тестової вибірки.

### Алгоритми машинного навчання
- **KNeighborsClassifier** — метод k-найближчих сусідів для класифікації
- **DecisionTreeClassifier** — дерева рішень з різними налаштуваннями
- **VotingClassifier** — базове ансамблювання (soft voting)
- **LogisticRegression** — використовується в ансамблі

### Методи оптимізації
- **GridSearchCV** — вичерпний пошук по сітці гіперпараметрів
- **RandomizedSearchCV** — стохастичний пошук (ефективніший для великих просторів)
- **Cross-Validation** — k-fold кросвалідація (3-5 фолдів)

### Препроцесинг даних
- **StandardScaler** — нормалізація числових ознак (z-score)
- **OneHotEncoder** — кодування категоріальних змінних
- **ColumnTransformer** — паралельна обробка різних типів ознак
